> 继续执行更新：本报告第 1–5 节保留初次视觉评审及当时方案；首页与五 Tab 的方案现已开始落地，当前结果见文末“实际整改”。不能再把首页 18 个入口当作新版本状态，也不能把局部整改扩大为全部玩法视觉验收通过。

## 判断

**视觉验收未通过。** 本轮恢复了可靠的绘制比例、触摸坐标、安全区、公共排版和核心流程，但当前画面仍有明显原型特征。不能把修复缩放、生成数千帧、增加 drawImage 调用或测试通过表述为“所有界面已变好”。

证据为微信开发者工具实际截图 `build/qa-evidence/final-home.png`、`final-mine-idle.png`、`final-games-scroll.png`，以及大逃杀、地下城、签到、卡牌实测。截图中的设备显示比例为 77%；评审不把窗口里显示得小直接等同于真机字号不达标，也不声称已完成所有 680 路由的逐屏视觉检查。

## “修坏了”与历史现状

- 原 Canvas 代理只对部分几何坐标缩放，字体、路径、圆角未统一，DPR 高时页面比例失真。该实现源于初始基线 `49333db`，早于本轮 QA；现已改为原生变换并通过六个浏览器 Canvas 场景。
- 已有文档明确界定当前界面为功能等价暗色重绘，原布局并未像素级还原。素材脱敏后采用自制程序化画面，和原产品外观存在差异。
- 当前美术不足不能只归因于渲染错误：相似深色卡片、入口过密、角色过小、核心玩法场景弱，修复缩放后仍然存在。

## 具体整改方向

采用 `.impeccable.md` 中暂定的自有“像素冒险岛”方向。下表保留初次评审提出的方案；首页及公共导航的实际落地见文末，玩法场景化和真机验收仍未完成：

| 优先级 | 当前问题及影响 | 具体设计 | 验收方式 |
|---|---|---|---|
| P1 | 首页像功能目录，第一次进入不知道先玩什么 | 用有角色的岛屿场景作主体；设置一个“继续冒险/开始一局”主入口，三项常用玩法；更多玩法留在游戏 Tab | 新玩家能在 5 秒内说明当前主操作；核对真实截图、点击和返回 |
| P1 | 玩法页都是面板与文字，玩家难以读懂局势 | 大逃杀突出房间、门耐久、人物；地下城突出砖块与剩余票；对战突出双方状态；卡牌突出卡面与收集进度 | 对应场景在进入、操作中、结算和失败四种状态有一致表现 |
| P1 | 字号层次跨度小，快捷入口密度过高 | 正文优先 14–16 CSS px，主标题 20–24 px；主操作至少 44×44 px；减少小字说明和两层密集网格 | 320/375/390/430 CSS px 宽度截图，长文案无裁切；真机手指点击 |
| P2 | 角色和特效像零散贴图，整体构图不统一 | 统一角色比例、像素网格、光源、图标语义；提高场景占比，减少空角落里的小动画 | 素材拼板和游戏实际画面一起评审；不以素材数作为完成标准 |
| P2 | 奖励仅是数字变化，操作结果弱 | 将金币、签到、卡牌奖励集中到当前动作附近，短暂反馈后给出继续操作 | 快速连点、弱网和重复返回下不会多发奖励或挡住按钮 |

可用 Impeccable 的 `/distill`、`/arrange`、`/typeset`、`/normalize`、`/polish` 执行上述设计，但命令名本身不是验收结果。

## 典型使用者检查

- 首次玩家：看到首页 18 个入口，难以选择；“NX”“生态大厅”没有解释其用途。先突出一个开始动作，再按玩法解释消耗和目标。
- 单手手机玩家：底部导航位置合理；首页快捷按钮小、紧密，频繁中断后的真实进度恢复尚需真机与持久化验收。
- 低视力或依赖辅助功能的玩家：Canvas 内容在工具可访问性树中主要表现为图像，当前没有完成屏幕阅读器可用性验收；小字、文本对比度与替代操作需单独测量。

## 本轮已完成的视觉相关修复

原生 Canvas 变换、DPR 输入一致、安全区回退、顶部标题与余额分行、首页内容分组、五 Tab 列表行高与裁切、滚动末项可达、footer 完整可见、玩家文案去除工程占位值。详见 `QA_RECHECK_2026-09-06.md` 的递归记录。专业美术重制、全玩法版式重做与真机视觉验收仍未交付。

## 实际整改（继续执行）

- 首页移除 12 个同权快捷入口，改为岛屿场景与地下城主操作、三项热门玩法、签到和卡牌两个日常入口；更多玩法通过游戏 Tab 或独立“查看全部玩法”进入。
- 矿工动画从 40 调整为 88 逻辑像素，嵌入海面、岛屿和树木场景；主操作采用暖色底与深色文字，布局没有新增位图依赖。
- 五 Tab 移除重复面板堆叠，改为章节页头、像素编号、路线和分隔线；主要列表名称 17 px、说明 14 px，并按实际文字测量截断长文案。
- 我的页突出真实昵称、经验和资源余额；六个工具按钮与更多服务共用滚动内容区，继续保持无轮询。
- 移除所有页面右下角的全局氛围小窗；玩法自身的场景动画与结算反馈保留，避免随机装饰图层覆盖真实内容。

# FINAL_LAUNCH_DECISION

> Section 79/97/98：首发取舍与上线能力评级。原则：FULL CLONE 保留完整生态，WECHAT RELEASE 合规适配；发布版必须是"内容丰富的游戏"，不砍成空壳（Section 80）。

## KEEP（首发必保留——构成完整回流循环）

每日任务/签到 → 短局玩法（大逃杀门票版/地下城/竞技场/Boss/斗猿/弹珠/虎口逃生/吃鸡/运动会/拔河/炸猴王）→ 资产（金币/体力/奖券/宝石/金沙/矿石/黄金）→ 长线成长（猿矿场/黄金矿场/宇宙探索/卡牌合成/扭蛋兔养成）→ 收集展示（图鉴/徽章）→ 赛季（SEASON_SCORE 7 天周期 + 排行）→ 邮件/公告回流。

Rationale：以上全部为服务端权威、无现金语义、tests 全绿；构成 Section 80 要求的完整闭环。

## CUT（首发永久/暂时移除）

现金钱包/提现（十屏沙盒桥在 FULL 保留，RELEASE 无任何调用路径）、下注现金语义、现金红包结算、付费随机抽取、P2P 可兑付交易/赠送/租赁、数字拍卖竞价、代理保证金/分销提现、实物兑奖闭环、Android 原生 SDK（广告/推送/人脸/自更新）。

每项共同理由：Compliance Risk=高（类赌博/资金循环/审核拒审）、Revenue Impact=0（本就不可合法接通）、Alternative=赛季积分/NPC 兑换/固定奖励（已实现）。

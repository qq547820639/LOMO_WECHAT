# 2026-09-06 审计与处置记录

## 范围

- `LOMO_WECHAT_FORMAL_MIGRATION`：TypeScript 服务端、客户端、双发布构建、资源/路由验收和测试。
- `inputs/cleanroom/lomo_wechat_migration`：clean-room 基线的构建依赖、运行时冒烟和模块注册。
- 交付边界：只处理本地工程可验证的问题；不把模拟后端或静态 APK 证据当作真实线上能力。

## 决策与处置

| 发现 | 决策 | 处置 |
|---|---|---|
| clean-room `npm test` 无 `tsc` | 阻断可复现构建 | 将 `typescript` 加入开发依赖并生成锁文件 |
| clean-room 负数物品/费用输入 | 可导致库存反向增加 | 拒绝负数或非整数 `takeItem`/费用，并加入冒烟断言 |
| clean-room 本地存档未校验 | 损坏存档可导致运行时崩溃 | 增加 `isPlayerState` 结构校验，异常存档回退初始状态 |
| 管理重置仅由 `APP_ALLOW_ADMIN=1` 保护 | 高风险，必须双重条件 | 增加 `APP_ADMIN_TOKEN` 与常量时间比较；缺少/错误令牌返回 `ADMIN_AUTH_REQUIRED` |
| 会话令牌永久有效 | 高风险，支持撤销 | 令牌携带 7 天过期时间并签名；令牌对应玩家记录不存在时拒绝 |
| 邀请令牌无生命周期 | 可滥用的长期凭证 | 增加 7 天有效期，过期返回 `INVITE_EXPIRED` 并删除记录 |
| 快照目录/写入不可靠 | 可能静默丢档 | 自动创建父目录，使用 `0600` 临时文件后原子重命名 |
| telemetry 路由未在鉴权失败后返回 | 未登录请求可写入遥测 | 补充鉴权失败立即返回并加入回归断言 |
| Ledger 批量幂等键按资产名冲突 | 同一批次重复资产可能错误重放 | 幂等键加入操作索引，并拒绝未知资产/非法 delta |
| 微信 DPR 输入坐标与画布像素混用 | 真机点击位置偏移 | 输入统一按 CSS 逻辑比例换算，Node tap 同步 start/end |
| 微信包默认加载 Node 进程内后端 | 真机可能缺少 Node 内置模块 | 微信运行时无远端 URL 明确失败；standalone 仅用于 Node/验收 mock |
| 微信登录失败仍降级为离线 code | 可能把未认证设备映射成账号 | 登录失败立即终止启动，不再向服务端发送伪造 code |
| 五大 Tab 长列表未应用滚动偏移 | 小屏无法访问后续功能族 | 根 Tab 绑定 Hub 滚动状态，拖动更新偏移并仅为可视行注册命中区域 |
| 排行榜请求失败只显示无操作的错误文字 | 用户无法判断是否可重试，服务端 `{ok:false}` 也会误显示为空榜 | 增加 loading/error 状态、错误详情和重试按钮，并将非 `ok` 响应转为可见错误 |
| 合规页点击后启动失败会锁死 `acked` | 网络或登录短暂失败时用户无法重新进入 | `completeBoot` 失败时重置合规页状态，保留可重试入口并加入客户端回归断言 |
| 新增约束缺少回归覆盖 | 验证不足 | 增加 `tests/security_hardening.ts`，覆盖篡改/过期/重置/恢复 |
| 运行时仍依赖历史未验证占位状态 | 配置无法作为可治理的上线输入 | 将 tuning 基线改为 `OWNED_LAUNCH_DEFAULTS`，增加 schema/provenance/effectiveFrom/owner 元数据；启动时做结构、数值范围和有限性校验，语义错误 fail-closed |
| 配置读取错误分支依赖 Node 专属类型 | 微信构建配置禁用 Node 类型时编译失败 | 改为结构化错误码读取，不引入 NodeJS 命名空间；重新执行双包构建验证 |
| clean-room 基线仍保留旧占位标记，且经济输入会静默取整 | 运行时语义与主工程不一致 | 同步为 `OWNED_LAUNCH_DEFAULTS` 元数据，拒绝分数费用、原型污染键和溢出库存/货币，并补充冒烟断言 |

## 剩余风险

- `/v1/auth/wechat` 仍是 clean-room 派生 OpenID 的参考实现；正式环境必须接入微信 `code` 换取接口、校验 `appid/secret`，并处理 code 一次性使用。
- 服务端当前是 JSON 快照/单进程内存模型；生产仍需数据库事务、并发控制、备份恢复演练、密钥托管和 TLS/反向代理配置。
- `full-clone` 的商业/结算接口是 TEST_CREDIT 沙盒，不能视为真实支付或提现已接通。
- 原服历史参数无法由静态 APK 验证；当前运行时使用的是可审计、版本化的自有默认参数，不再把历史不可验证性当作工程占位。
- 未在真实微信开发者工具、真机 TCC/平台合规审核环境中验证；本地证据不能替代上线审批。

# PRIVACY_DATA_MAP

> Section 59：每项数据最小必要声明。RELEASE 配置 `privacyConsentRequired: true`。

| 数据 | 用途 | 来源 | 存储 | 保留 | 第三方 | 用户控制 |
|---|---|---|---|---|---|---|
| wx.login code | 换取登录身份 | 微信平台 | 服务端即时消费，不落库 | — | 微信(官方) | 不可选（登录必需） |
| openId/内部 playerId | 账号标识 | 服务端派生 | 服务端玩家表 | 账号存续期 | 无 | 注销即删 |
| token | 会话鉴权 | 服务端签发 | 客户端内存/缓存 | 会话期 | 无 | 重登即换 |
| 昵称（默认"玩家XXXX"） | 展示 | 服务端生成 | 服务端 | 账号存续期 | 无 | 可改（预留） |
| 玩法计数器/时间戳 | 防重放/日常重置/生产结算 | 玩法过程 | 服务端+本地缓存 | 账号存续期 | 无 | 清缓存不影响服务端数据 |
| 账本流水 | 资产安全/客服纠纷 | 玩法结算 | 服务端 | 账号存续期 | 无 | 可查询（/v1/economy/ledger） |
| 遥测事件（launch/feature_enter/game_finish/error/fps） | 产品改进 | 客户端 | 服务端环形缓冲(5000 条) | 滚动覆盖 | 无 | 不含设备指纹/位置/通讯录 |
| 防沉迷状态 | 合规 | 服务端判定（本版默认成年占位） | 服务端 | 账号存续期 | 国家实名体系(接入后) | 不可绕过 |

**明确不收集**：手机号、位置、通讯录、相册、剪贴板、设备列表、其他 App 列表。原 APK 的 38 项权限（后台定位/READ_PHONE_STATE/QUERY_ALL_PACKAGES/安装包等）全部不移植。

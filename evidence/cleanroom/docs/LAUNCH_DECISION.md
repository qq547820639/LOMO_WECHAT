# 上线版本取舍表

## 决策原则

上线目标不是把 Android App 的所有商业行为塞进小游戏，而是保持游戏玩法生态、成长目标和内容循环，同时删除会把“游戏结果 → 可兑现价值”连起来的通道。

## 首发核心循环

`每日任务/短局 → 体力/金币/卡牌 → 猿系/飞船/矿场成长 → PVE/PVP/赛季 → 图鉴与外观 → 回流任务`

首发 monetization 建议优先级：

1. 合规激励广告：仅给额外体力/固定软币，不给现金等价物，不与提现绑定。
2. 固定价外观/通行证类虚拟商品：具备版号/支付资质后接入，服务端验单。
3. 禁止把付费货币用于随机抽取上线前核心商品。

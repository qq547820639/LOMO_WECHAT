# 00 — 全量复刻最终裁决

## 决策
不再把项目收缩成单一“方块兽抢夺战”。目标改为：**以微信小游戏为壳，最大程度复刻 APK 4.3.7 的完整用户体验与系统关系。**

### 复刻原则
- Android Activity ≠ Cocos Scene；但每一个业务 Activity 都必须在路由表中有对应目标页/弹窗/子界面。
- 原功能能以游戏 UI 实现的，行为保持一致。
- 原 Android SDK 能力（支付宝、推送、客服、Face SDK、广告 SDK）抽象成 Platform Adapter。
- 原素材先按原名、原时序、原层级迁移，第二轮才做压缩/替换。
- 所有资产名称、余额、流水、交易记录、排行榜、历史记录、背包/仓库关系先全部建模。

### 不再删掉的板块
猿宇宙、无聊猿卡、宝石矿场、猿石/金沙/勋章、卡牌、闪卡、盲盒、福袋、抽签、地下城、大逃杀、匕首、抢劫杀手、竞技场、斗猿场、Boss 挑战、虎口逃生、今晚吃鸡、弹珠、运动会、拔河、炸猴王、多人矿坑、猿石魔兽、宇宙探索、黄金矿场、交易中心、寄售、竞拍、拼团、店长/代理、邀请裂变、商城/物流。

### 唯一不直接接通的部分
涉及**真钱下注、随机输赢后直接形成可提现价值、实际提现/现金红包结算**的接口只做测试态占位。界面、按钮、流水、状态流可以按原体验复刻，但底层使用不可兑付的沙盒资产。

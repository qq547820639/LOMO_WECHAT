# 03 — 反编译边界与剩余未知项

## 静态分析已经能确定
- 模块/Activity 全貌。
- 大量原始动画、PNG 序列、音频与资源名称。
- 玩法入口和账户/资产/记录/订单等页面结构。
- 部分规则文案（例如方块兽抢夺战）。

## 静态 APK 无法可靠确定
该 APK 使用 `com.stub.StubApp` 与 `libjiagu*`，说明业务 DEX/方法受壳保护。仅凭当前静态包不能声称已经恢复：
1. 线上 API BaseURL 与全部接口。
2. 请求签名/加密算法的业务实现。
3. 服务端实时概率、奖池、费率、风控参数。
4. 每个按钮的精确状态迁移。
5. 某些页面的最终像素布局（res 文件名被资源混淆）。

因此“1:1”实施采用三层证据优先级：
**运行期行为/接口 > APK资源/页面名 > 公开历史截图/玩法资料 > 推断。**

当前包已经把所有无法确认的数值抽成 `RemoteConfig`，后续只替配置，不需要再改客户端结构。

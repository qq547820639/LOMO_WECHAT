# 04 — 全量照搬的实施顺序

不是“先做一个缩水 MVP”，而是按依赖关系把完整系统接起来。

## Wave 0：壳与基础设施
Cocos 工程、路由、账号、RemoteConfig、资源加载、统一资产账本、记录中心、服务器时间。

## Wave 1：原主首页 + 猿宇宙资产基础
主页、猿宇宙、资产中心、卡/宝石/勋章/猿石/NDTU/金沙、仓库/保险箱、好友/邀请。

## Wave 2：高黏性核心
大逃杀 + 匕首 + 抢劫杀手 + 记录/排行；地下城；竞技场/Boss/斗猿场。

## Wave 3：生产经济
无聊猿卡矿场、私人/好友/多人矿坑、黄金矿场、猿石魔兽、宇宙探索。

## Wave 4：小游戏矩阵
虎口逃生、吃鸡、弹珠、运动会、拔河、炸猴王、动物玩法。

## Wave 5：潮玩与卡牌
盲盒、福袋、闪卡、合成拆分、卡柜、提货/物流、数字潮玩。

## Wave 6：交易生态
交易中心、寄售、订单、竞拍、拼团、店长/代理、设计师/IP合作。

## Wave 7：平台适配
微信登录、分享、客服、广告、支付等平台能力适配；真钱结算类功能保持沙盒/占位，直到有合法授权与对应能力。
